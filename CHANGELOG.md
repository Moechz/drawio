# Changelog

All notable user-visible changes to the Draw.io TOS application package.

## 32.6.10-1 — 2026-11-14

### Added
- First release. Draw.io (`jgraph/drawio:32.6.10`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8031 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/drawiodocker/`.
